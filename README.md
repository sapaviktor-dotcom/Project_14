# Система управления продуктами и категориями

## Описание проекта

Данный проект реализует базовую систему управления товарами и категориями для интернет-магазина.

### Основные сущности



### Архитектурные решения
- **Абстрактный класс BaseProduct**: обеспечивает единый интерфейс для всех продуктов
- **Абстрактный класс BaseStorage**: общий интерфейс для хранения товаров (категории и заказы)
- **Класс-миксин ProductMixin**: логирует создание объектов
- **Наследование**: Smartphone и LawnGrass наследуются от Product

#### Класс Product (Товар)
Базовый класс для всех товаров с атрибутами:
**name (str)** - название товара
**description (str)** - описание товара
**price (int/float)** - цена товара (с валидацией)
**quantity (int)** - количество в наличии

Особенности:

Приватный атрибут **__price** с геттером и сеттером
Валидация цены (не может быть ≤ 0)
Класс-метод **new_product()** для создания из словаря с проверкой дубликатов
Магический метод __add__ для сложения товаров

#### Smartphone (наследник Product)
Дополнительные атрибуты:
**efficiency** - производительность
**model** - модель
**memory** - объем встроенной памяти (ГБ)
**color** - цвет
- Поддержка всех методов родительского класса

#### LawnGrass (наследник Product)
Дополнительные атрибуты:
**country** - страна-производитель
**germination_period** - срок прорастания (дней)
**color** - цвет
- Поддержка всех методов родительского класса

#### ProductMixin (Миксин)
Автоматически логирует создание объектов Product и его наследников


#### Класс Category (Категория)
Организует товары по категориям.
Атрибуты класса:
**category_count** - общее количество созданных категорий
**product_count** - общее количество товаров во всех категориях

Атрибуты экземпляра:
**name (str)** - название категории
**description (str)** - описание категории
**__products (приватный)** - список товаров
Атрибуты заполняются автоматически при создании каждого нового объекта Category.

#### Методы:
**add_product()** - добавление товара с проверкой типа (isinstance)
**@property products** - форматированный вывод списка товаров
**get_total_quantity()** - общее количество товаров в категории
**get_total_price()** - общая стоимость всех товаров

Итератор:

Реализует __iter__ и __next__ для перебора товаров

#### Order (Заказ)
Управляет заказами на один товар.
Атрибуты:
**product** - ссылка на товар
**quantity** - количество

#### Методы:

**get_total_price()** - расчет итоговой стоимости
**get_total_quantity()** - получение количества


## Реализованный функционал

1. **Создание товаров и категорий**
   - Классы с корректной типизацией атрибутов
   - Инициализация с обязательными параметрами

2. **Автоматический подсчет**
   - Каждая новая категория увеличивает `category_count`
   - Каждый товар в категории увеличивает `product_count`

3. **Загрузка из JSON** (дополнительное задание)
   - Функция `load_data_from_json()` для загрузки данных из файла
   - Автоматическое создание объектов Product и Category из JSON
   - Корректная обработка всех типов данных

4. **Инкапсуляция и приватные атрибуты**

#### Класс Product
- **Приватный атрибут `__price`** - цена товара защищена от прямого доступа
- **Геттер `@property`** - для получения значения цены
- **Сеттер `@price.setter`** - для установки цены с валидацией:
- Проверка на положительное значение
- При попытке установить цену ≤ 0 выводится сообщение: "Цена не должна быть нулевая или отрицательная"

 
#### Класс Category
- **Приватный атрибут `__products`** - список товаров защищен от прямого доступа
- **Метод `add_product()`** - для добавления товара в категорию
- **Геттер `@property`** - для получения списка товаров в форматированном виде
- Добавление товаров с проверкой типа (используется `isinstance()`)

#### Магические методы
**__str__** 
Product: Форматированный вывод информации о товаре
Category: Вывод названия категории и общего количества товаров
**__add__**
Реализован для класса Product
Возвращает сумму произведений цены на количество для двух товаров
При попытке сложить объекты разных классов выбрасывается ошибка `TypeError`.
Для проверки типа используется функция `type()`.

### Дополнительный функционал
**Класс-метод new_product()**
Создает новый товар из словаря данных
Автоматически проверяет наличие дубликатов в глобальном списке
При обнаружении дубликата:
Обновляет количество (складывает с новым)
Обновляет цену, если новая цена выше
Обновляет описание, если оно отличается
Возвращает существующий или новый объект Product

### Ограничение добавления 
Метод `add_product()` в классе `Category` проверяет, что добавляемый объект 
является экземпляром `Product` или его наследником.
Для проверки используется функция `isinstance()`.

**Итератор ProductIterator**
Позволяет перебирать товары в категории в цикле for
Реализует методы **__iter__** и **__next__**
Автоматически обрабатывает конец списка (StopIteration)
