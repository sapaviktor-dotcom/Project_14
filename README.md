# Система управления продуктами и категориями

## Описание проекта

Данный проект реализует базовую систему управления товарами и категориями для интернет-магазина.

### Основные сущности

#### Класс Product (Товар)
Представляет товар с следующими атрибутами:
- **name** (str) - название товара
- **description** (str) - описание товара
- **price** (int/float) - цена товара (может быть с копейками)
- **quantity** (int) - количество в наличии (измеряется в штуках)

#### Класс Category (Категория)
Представляет категорию товаров с следующими атрибутами:
- **name** (str) - название категории
- **description** (str) - описание категории
- **products** (List[Product]) - список товаров в категории

### Атрибуты класса Category
- **category_count** - общее количество созданных категорий
- **product_count** - общее количество товаров во всех категориях

Эти атрибуты заполняются автоматически при создании каждого нового объекта Category.

## Реализованный функционал

1. **Создание товаров и категорий**
   - Классы с корректной типизацией атрибутов
   - Инициализация с обязательными параметрами

2. **Автоматический подсчет**
   - Каждая новая категория увеличивает `category_count`
   - Каждый товар в категории увеличивает `product_count`

3. **Загрузка из JSON** (дополнительное задание)
   - Функция `load_data_from_json()` для загрузки данных из файла
   - Автоматическое создание объектов Product и Category из JSON
   - Корректная обработка всех типов данных

4. **Инкапсуляция и приватные атрибуты**

#### Класс Product
- **Приватный атрибут `__price`** - цена товара защищена от прямого доступа
- **Геттер `@property`** - для получения значения цены
- **Сеттер `@price.setter`** - для установки цены с валидацией:
  - Проверка на положительное значение
  - При попытке установить цену ≤ 0 выводится сообщение: "Цена не должна быть нулевая или отрицательная"
  

#### Класс Category
- **Приватный атрибут `__products`** - список товаров защищен от прямого доступа
- **Метод `add_product()`** - для добавления товара в категорию
- **Геттер `@property`** - для получения списка товаров в форматированном виде

#### Магические методы
**__str__** 
Product: Форматированный вывод информации о товаре
Category: Вывод названия категории и общего количества товаров
**__add__**
Реализован для класса Product
Возвращает сумму произведений цены на количество для двух товаров


### Дополнительный функционал
**Класс-метод new_product()**
Создает новый товар из словаря данных
Автоматически проверяет наличие дубликатов в глобальном списке
При обнаружении дубликата:
Обновляет количество (складывает с новым)
Обновляет цену, если новая цена выше
Обновляет описание, если оно отличается
Возвращает существующий или новый объект Product

**Итератор ProductIterator**
Позволяет перебирать товары в категории в цикле for
Реализует методы **__iter__** и **__next__**
Автоматически обрабатывает конец списка (StopIteration)


**Тестирование**
   - Полное покрытие всех классов и методов
   - Тесты проверяют:
     - Корректность инициализации объектов
     - Автоматический подсчет категорий
     - Автоматический подсчет товаров
     - Загрузку данных из JSON
     - Корректность инкапсуляция и приватных атрибутов
